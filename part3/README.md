# Phonebook Backend (Full Stack Open - Parte 3)

Aplicação backend em Node.js / Express para a lista telefônica (Phonebook), servindo a API REST e a interface construída em React (build estático).

## Deploy em Produção

- **URL da Aplicação Online:** https://helsinki-fullstack-w3s5.onrender.com/

### Como implantar no Render:
1. Conecte sua conta do GitHub ao [Render](https://dashboard.render.com/).
2. Crie um novo **Web Service**.
3. Selecione o repositório `Helsinki-fullStack`.
4. Defina as seguintes configurações:
   - **Root Directory:** `part3`
   - **Build Command:** `npm install`
   - **Start Command:** `node index.js`
5. Clique em **Deploy Web Service**.

## Scripts Disponíveis

Na pasta `part3`:
- `npm start`: Inicia o servidor em modo de produção.
- `npm run dev`: Inicia o servidor em modo de desenvolvimento com `nodemon`.
